【完成项】
1. 新增 packages/game-core/src/bank.ts（约 260 行）：
   - 类型 BankLoan（loanId、borrowerId、seatId、principalCents、remainingCents、rateBps、issuedRound、dueRound、lastInterestRound、status、origin）
   - 状态 ACTIVE/REPAID/DEFAULTED，来源 NORMAL/OVERDRAFT
   - borrowFromBank：GOOD 信用、金币>0、无本人未结清银行贷款（按 borrowerId 过滤）、金额 ≤ 金币一半向下取整；透支贷款不受这些限制
   - accrueInterest：逐轮复利，自动补算漏掉的轮次，计息上限为 dueRound，逾期不再计息
   - repayBankLoan(loan, cents, currentRound)：仅 ACTIVE；DEFAULTED 永久拒绝；早于放款轮、逾期、未计息一律拒绝
   - settleDue(loan, decision, availableCents, currentRound)：到期当轮决策；超过到期轮按“超时未决策”直接失信并冻结欠款；返回 { loan, paidCents }
   - defaultedBankDebtCents / totalDebtCents：汇总函数，汇总越界抛错
   - 错误码 14 个，含 LOAN_OVERDUE、INTEREST_NOT_ACCRUED、INVALID_ORIGIN、INVALID_DECISION
2. 新增测试 packages/game-core/tests/bank.test.ts（31 条）：覆盖 55/60.50/66.55 复利、0.05 金币半入、5051 分上限向下取整、
   当轮不计息、到期边界（余额恰好够/差 1 分）、逾期失信、逾期不计息、漏轮补息、失信后禁止还款且金额冻结、
   多笔贷款互不影响、私人负债不影响资格（D1）、透支不受上限、跨借款人过滤、非法枚举/轮次/金额、不可变性。

【两轮复核发现并修掉的问题】
第一轮（Qoder）：
- 到期时序未强制：ACTIVE 贷款可越过 dueRound 继续计息并结清 → 改为当轮精确决策
- 测试把错误行为固化成期望 → multiple_bank_loans 重写
- 跳轮静默少收利息 → 改为逐轮补算
- origin/decision 无运行时校验（乱写 origin 可绕过 50% 上限）→ 补校验
- existingLoans 未按借款人过滤（会堵死其他玩家）→ 已过滤
- settleDue 不返回实际扣款额（调用方易多扣）→ 返回 { loan, paidCents }
- repayBankLoan 无轮次参数（逾期可小额拖回 ACTIVE）→ 已补
第二轮（Qoder）：
- 逾期一律抛错，导致“超时 → 该笔失信”没有出口 → 改为 currentRound > dueRound 直接 DEFAULTED
- accrueInterest 在 map 内抛错会阻断全桌计息 → 改为不抛错、按 dueRound 封顶
- 还款缺少与结算对称的“先计息”保护 → 已补 INTEREST_NOT_ACCRUED
