单元 08A 运行与验收说明（含复核修复）
================================================================
环境（本机实测）：
- Node v24.18.0
- pnpm 11.7.0（corepack pnpm 同版本）
- Windows PowerShell 5.1

一、安装与验证命令
pnpm install
pnpm typecheck
pnpm -s test
pnpm -s build
pnpm dev            # 服务端 8000，0.0.0.0；浏览器访问 http://localhost:8000/

实测：
- pnpm typecheck：tsc --noEmit -p tsconfig.json，exit 0
- pnpm -s test：61 文件 / 684 条全部通过，6.45s
  （646 旧 + 32 初版 + 6 条 S2 语义测试）
- pnpm -s build：138 modules，CSS index-D263Ed7h.css 14.79 kB（gzip 3.50 kB），
  JS index-HFP1Drkx.js 417.72 kB（gzip 122.44 kB），463ms

二、入口位置与逐步操作
1. 首次进入
   - localStorage 可用且未写过 richman.tutorial.seen.v1 时自动弹出教程；
     第 1 页显示“第 1 / 5 页”，上一步禁用。
   - “下一步”翻到第 3 页“玩家之间借钱”；该页应显示：
     “同一时间只处理一个待答复请求（由当前行动者发起）”；
     “出借人最多可收 = 剩余应收与对方当前金币的较小值”；
     “借出当轮不能催收，之后可在自己的行动窗口或自救阶段催收”；
     “借款人在自己的行动窗口或自救阶段可以还款”。
   - 顶部“跳过教程”“关闭教程”，末页“我知道了”，三者都写 seen 并关闭。
2. 入口页（未进房）
   - “加入”下方“新手教程”“规则说明”两个 .link。
3. 大厅
   - lobby-actions 下方出现“新手教程”“规则说明”（App 传可选 props 时）。
4. 对局内
   - self-actions 在“查看其他玩家”“债务中心”之后有“教程与规则”“规则说明”；
     点击只打开阅读层，不发命令、不消耗行动、不改步骤卡。
5. 规则页
   - 单个可滚动面板，R1～R8；规则页截图分别滚到“私人借贷”和
     “税收与危险自救”节。私人借贷应显示新的较小值/当轮/行动窗口口径；
     自救节应显示“紧急借款、催收、放弃”“同意、拒绝或取消”
     “不能新借银行贷款”，不得出现“还款与放弃”。

三、存储 key
- richman.tutorial.seen.v1，写入值固定 "1"。
- 只表示是否看过教程；不含 token、房间码、昵称、座位等身份数据。
- getItem/setItem 抛异常不崩；storage 完全不存在时不自动弹，
  入口页手动入口仍可用（已记录边界，见注意事项）。

五、360px 已知边界
- 教程/规则面板在 ≤560px 时占满宽度，操作按钮单列全宽；长段落可任意断行。
- 规则页是单面板滚动，不折叠章节；8 节需要滚动查看。
- 覆盖层内部滚动；页面本身不横向滚动。
- 未验证：实体 Android/iPhone 的 100dvh、刘海/底部安全区、软键盘弹起遮挡；
  这些留给 08B。截图是无头桌面 Edge 的移动视口，不是实体手机。

六、复核修复重点验收
- M1：私人借贷两处都出现“剩余应收与对方当前金币的较小值”“借出当轮不能催收”
  “在自己的行动窗口或自救阶段”，且没有“上限=对方当前金币”
  “上限为对方当前金币”“随时催收”“随时还”。
- M2：两处都出现“同一时间只处理一个待答复请求”，且没有
  “同一出借人可以同时收到多人的请求”。
- M3：P4/R6 段落/要点统一为“紧急借款、催收、放弃”，无“还款与放弃”；
  R6 要点含“同意、拒绝或取消”和“不能新借银行贷款”。
- S2：tutorial-pages.test.ts 11 条中 6 条为语义测试；反向探针用旧文案
  证明这些谓词会变 false。
- S1：storage=null 例外已写为“已记录边界”，不再宣称满足规格第 48 行。
- D6 缺口记录在下一阶段交接：engine 全局单 pendingRequestId，
  “出借人可同时收多个请求”未实现。
