六、测试缺口（指出该加什么断言）
------------------------------------------------------------
1. 银行到期余额不足立即失信（对应必须修 #1）：
   构造 round=N、dueRound<=N、remaining > 借款人余额；发任意一条命令（甚至非借款人命令）后断言
   phase 直接 ACTION、该笔 DEFAULTED、credit DEFAULTED、deadline 不是 now+bankDueSec、
   事件里没有 BANK_DUE_PENDING 且 BANK_LOAN_DEFAULTED.reason="insufficient_funds"。
   同时改 tests/full-game.test.ts:120-127（不应再需要人工决策）。
2. 取消请求（对应必须修 #2）：
   - ACTION：请求 → 借款人 CANCEL → status CANCELLED、pendingRequestId=null、
     currentSeatId 前进（行动已消耗）；之后 lender 再 ACCEPT 返回 REQUEST_EXPIRED 且无转账；
   - TAX：danger 请求 → CANCEL → deadline 回到 dangerDeadlineMs、仍 DANGER、
     可在 2 秒后重新请求；
   - 第三人取消 → UNAUTHORIZED，请求仍 PENDING。
3. 2 秒请求间隔（对应必须修 #3）：
   自救拒绝后 t+1999ms 再发 → 拒（明确错误码/文案）；t+2000ms → 成功；
   断言两次尝试都不改变 dangerDeadlineMs，且拒绝那次不消耗任何状态。
4. 超时命令的提交语义：
   下注截止后提交 → outcome.ok=false，但 version=before+1、phase 已推进、
   events 恰含一次 BET_SETTLED、bets 已清空；再发同轮 SUBMIT_BET → 拒绝且余额不再变。
   对照：纯拒绝（NOT_YOUR_TURN / ALREADY_LOCKED）version、eventSeq、deadline 全不变
   （后者已有，建议扩到 eventSeq）。
5. 赌博不变量回滚：
   篡改 cents 使 1 倍猜输出现负余额 → outcome=RULI_INVARIANT（gamble.ts NEGATIVE_BALANCE），
   断言所有玩家余额、bets、bankLoans、version、eventSeq 全部保持原样；
   near-MAX 猜赢触发 BALANCE_OVERFLOW 同样断言整次回滚、不生成 OVERDRAFT。
6. 视图隐私用真实数据：
   现有 engine-round.test.ts:288-320 只放了 requests，privateLoans/bets 为空，属于“假绿”。
   应塞入真实 ACTIVE/FROZEN/BAD_DEBT 私人合同与他人已锁定下注，断言第三人
   JSON.stringify(view) 不含 loanId/remainingCents/principalCents/betCents/guess/leverage，
   且本人视图全部可见；公开列表不含 ACTIVE 银行贷款金额（只允许失信欠款）。
7. 全员破产：两人余额均小于应缴税，按座位先后破产 → GAME_OVER 且 winnerId===null，
   并断言两人的税都已被处理（taxIndex===2），不是剩下谁谁赢。
8. 税收节奏与座位序：
   第 1/2/4/5 轮永不进入 TAX；第 3/6/9 轮 TAX_CHARGED 事件的 seatId 序列严格递增等于
   本轮开局存活座位；每人每轮恰好一条 TAX_CHARGED。10 人 full-game 现在只断言最终余额。
9. 银行到期稳定次序与单次结算：
   同座位多笔逾期 + 多座位逾期，断言 BANK_DUE_PENDING 顺序 = 座位→dueRound→loanId，
   每笔只出现一次，全部结束后同一命令内进入 ACTION。
10. 重复 ID 防御对称性：privateLoans/requests 放入两条同 ID 夹具，
    调还款/催收/同意，断言抛 RULE_INVARIANT 或明确拒绝且不双写（当前 replacePrivateLoan 无守卫）。
11. 事件隐私：对第三人可收到的事件流做 JSON 断言，不含私人本金/还款额/催收额；
    若采用 audience 字段，断言非当事人过滤后事件数变少且不含私人类型。
12. 非法规避行动消耗：
    自借（lenderId===playerId）、向破产者借款、金额非法 → 返回错误后
    currentSeatId 与 windowDeadlineMs 均不变（R02“失败不消耗行动、不重置倒计时”）。
