M1. 催收文案同时写错“上限”和“随时”：实际可收上限是
    min(剩余应收, 对方当前金币)，且借出当轮不能催收。

位置 1：apps/web/src/tutorial/pages.ts:48
代码原文：
  "出借人可随时催收（上限=对方当前金币），借款人可随时还。..."

位置 2：apps/web/src/tutorial/rules.ts:62
代码原文：
  "同意后立刻转账；每轮按约定利率计息；出借人可随时催收，上限为对方当前金币；借款人可随时还。"

引擎真值：
- packages/game-core/src/private-loans.ts:421
    const collectibleCents = Math.min(loan.remainingCents, Math.max(0, borrowerCents));
  packages/game-core/src/engine.ts:1190 同样使用
    const limitCents = Math.min(loan.remainingCents, Math.max(0, borrower.cents));
  所以剩余应收 500、借款人 1000 时最多只能收 500，不是“对方当前金币 1000”。
- packages/game-core/src/private-loans.ts:410-412
    if (currentRound < loan.issuedRound + 1) throw INVALID_ROUND("借出当轮不能催收");
  所以“随时催收”也不成立：至少下一轮起，且仍受利息是否计入/行动窗口约束。
- handoff/规则决策表.txt:51 明确写：
  “催收上限 = min(剩余本息, max(0, 借款人金币))；借出当轮不能催。”

可执行探针（不改文件）：
1) 构造 loan.remainingCents=500、borrower.cents=1000，调用
   engine 的 COLLECT_PRIVATE cents=1000 → INVALID_AMOUNT/AMOUNT_EXCEEDS_COLLECTIBLE；
   调用 cents=500 才成功；
2) currentRound=issuedRound 时调用 collectPrivateDebt → INVALID_ROUND。
修复建议：
- 教程 P3 与规则 R4 改为“最多可收=剩余应收与对方当前金币的较小值；借出当轮不能催，
  之后在自己的行动/自救窗口内催收”；“借款人可随时还”建议改为“在自己的行动/
  自救窗口内可还”，避免“随时”与回合限制冲突。
- 补一条文案/规则测试，断言出现“min/较小值”“借出当轮不能催”，防止回退。
