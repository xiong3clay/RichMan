【本单元交付的 API（引擎直接复用）】
packages/game-core/src/private-loans.ts：
- createLoanRequest(input): LoanRequest
- acceptLoanRequest(request, ctx): { request, loan, borrowerCents, lenderCents }
- refuseLoanRequest / cancelLoanRequest / expireLoanRequest(request): LoanRequest
- accruePrivateInterest(loans, round): PrivateLoan[]
- repayPrivateLoan(loan, cents, currentRound, borrowerCents, lenderCents): { loan, paidCents, borrowerCents, lenderCents }
- collectPrivateDebt(loan, cents, currentRound, borrowerCents, lenderId, lenderCents): { loan, collectedCents, borrowerCents, lenderCents }
- settleBankruptcy(loans, bankruptPlayerId): PrivateLoan[]
- closeRequestsForBankrupt(requests, bankruptPlayerId): LoanRequest[]
- 汇总：privateDebtCents / receivableCents / frozenCents / badDebtCents

【引擎（单元 03）必须负责、bank/private-loans 不负责的事】
- 阶段限制：只有当前玩家在自己 ACTION（或危险自救）里能借款/还款/催收；BETTING 期间禁止一切经济操作。
- “发起请求即消耗行动”“拒绝/取消不退行动”“请求截止 = min(请求时限, 当前窗口截止)”。
- accept 时刷新 D5 风险快照（如果借款人在等待期间新增失信，出借人界面要能看到最新状态）。
- 命令去重与 version 校验（单元 04 才接网络，但引擎接口要预留 commandId）。
- 破产判定（金币为负且自救失败）→ 调 settleBankruptcy + closeRequestsForBankrupt + 银行贷款全部转 DEFAULTED。

【必须保持的语义】
- 同意才转账，且扣出借人/加借款人/建借条是一次原子结果；任何失败不能只改一方。
- 催收超过上限是拒绝（AMOUNT_EXCEEDS_COLLECTIBLE），不是静默封顶。
- BAD_DEBT / FROZEN 不再计息、不能还款、不能催收、不计入应收。
- 私人借款下一轮才首次计息。

【单元 03 开工前必须一起定的接口问题（Qoder 第三轮复核提出）】
1. applyCommand 需要 CommandContext：现签名是 (state, command, now: Date)，但赌博开奖需要注入随机结果，否则引擎只能内部取随机源、测试不可复现。建议改为
   applyCommand(state, command, ctx: { nowMs: number; drawResult: 0 | 1 })。
2. outcome 只有 code: string：R06 要求催收被拒时“返回合法上限”，现在上限只在中文 message 里，引擎只能解析字符串（AGENTS 明令禁止）。建议 outcome 增加 message 与结构化 details（如 { limitCents }）。
3. GameState 没有 eventSeq：GameEvent.seq 已有但无处赋值，事件日志连续性会断。建议 eventSeq 放进 GameState（或 context 并在快照里持久化）。
4. BANK_DUE 必须扫 dueRound <= round，不能只扫 === round：被跳过的逾期贷款会永远卡在 ACTIVE（还款被 LOAN_OVERDUE 拒、新贷款被 ACTIVE_LOAN_EXISTS 挡、信用永远 GOOD）。
5. bank.repayBankLoan 不接收金币数：R03 要求“不超过金币”，引擎必须自己校验余额并加测试，否则可能在非税收期把玩家扣成负余额。
6. 汇总函数（银行两个 + 私人两个）只支持全局：引擎必须按 playerId 过滤，误传全房贷款会把别人的欠债算进“我的总负债”并泄露隐私。建议接入视图前先加 playerId 参数。
7. 失信事件要带 defaultedAtRound / originalCents / reason（R04 要求保留历史且不叠加进总负债），现在没有字段。
8. 私人请求“最多一个 PENDING”只按借款人判断（D6 已确认），出借人可同时收多个请求。
