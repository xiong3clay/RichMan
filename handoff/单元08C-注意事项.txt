单元 08C 注意事项（音频 / 音量 / 静音 + 复核修复）
================================================================
1. 素材来源与许可证
   全部由 apps/web/scripts/make-audio.mjs 合成，无第三方采样；
   随项目仓库分发，与源码同一许可证。任何 WAV 修改都必须重跑脚本，
   并同步 src/audio/manifest.ts 的 AUDIO_SHA256 / AUDIO_BYTES；
   audio.test.ts 会逐文件核对 sha256、字节、头、时长、峰值、首尾和 PCM 均值。
   重跑两次必须 byte/sha 完全一致，不允许 Math.random、时间戳或外部采样。

2. BGM 直流偏移（M2 已修）
   - addNote 逐样本减 dc=(2*duty-1)；25% 旋律保留音色但均值归零。
   - 补偿后峰值会放大 1.5 倍，振幅已下调为 melody 30 / bass 20 / shaker 6；
     当前 bgm mean=0.043、peak=70、first/last=128，6 个文件 |mean|≤2。
   - 不要再把振幅调回 45/30/10，否则可能撞 100 钳位。
   - BGM 字节必须保持 352844，时长 16.000s；当前 sha256：
     811811013ae823036b41be3d5996c712fbd4e6bf5011b7db5952d19bc02bf3ac。

3. 严格模式与 dispose（M1 已修）
   - 禁止在 React unmount cleanup 里 audio.dispose()；StrictMode 会 mount→cleanup→mount，
     导致 dev 永远静音。
   - 只在真实页面离开时 pagehide dispose；effect cleanup 只移除 pagehide 监听。
   - dev Vite + StrictMode 实测 pointerdown 后确实 new/play bgm-loop.wav。
   - 生产 build 不执行 StrictMode 模拟 cleanup，但仍保持同样的 pagehide 释放。

4. 自动播放策略
   - unlock 前不创建 Audio、不调用 play；首次 pointerdown/keydown 才 unlock。
   - muted 持久化为 true 时，unlock 只创建 BGM 但不 play；setMuted(false) 才恢复
     （S1 修复）。
   - 不做预加载、不联网、不请求权限；音频 URL 只用 BASE_URL + audio/。
   - 首次手势前到达的事件音效会被跳过，这是策略取舍。

5. 音量/静音行为
   - 默认 {muted:false,bgmVolume:0.5,sfxVolume:0.7}，key richman.audio.v1。
   - setter clamp 0..1、保留两位小数；损坏 JSON/越界值回默认并覆盖写入。
   - playSfx 在 unlock 前、muted、sfxVolume=0、unavailable 时返回 false 且不创建。
   - 同一 now() 毫秒同名只播一次；同时最多 3 个，超出暂停最旧。
   - safePlay 同步 throw 返回 false；promise reject 会调用 onFailure：
     SFX 从 active 移除并 markUnavailable（S2 修复），不会占槽位。
   - activeSfxCount 是只读诊断 getter。

6. 事件去重（M3 已修）
   - App 使用 playedSfxSeqRef: Set<number>，derive 始终传完整 300 条事件；
     只播 Set 中未出现的 seq。不要退回 takeNewSfx 的 50 窗口。
   - events=[] / startRoom / onStarted / 房间销毁时 clear Set；新局 seq 1 可重播。
   - 400 批回归测试证明不会因 300 条窗口滚动而重播旧音效。
   - LOAN_REQUEST_CLOSED/EXPIRED 不带借款人，derive 依赖同批 LOAN_REQUESTED
     建立 requestId→borrower 映射；若 REQUESTED 被 300 条事件风暴淘汰，映射丢失，
     对应 lose 不播（已记录边界并测试）。
   - GAME_OVER winnerId=null → lose；ROUND_SETTLED 分支保留但 dormant：
     engine 当前只有 ROUND_STARTED，不得把 ROUND_STARTED 当结算。

7. UI 与层级
   - .audio-overlay fixed、z-index 30：高于内容、低于教程/规则 40。
   - 入口页、大厅、对局顶栏各有“声音”入口（aria-label="声音设置"）。
   - 面板三控件：静音 checkbox、背景音乐 range、音效 range；关闭、Esc、遮罩都能关。
   - 560px 面板通栏、滑杆换行、min-width:0；粗指针 range/checkbox ≥44px。
   - N7：panel onKeyDown 与 window keydown 仍可能都触发 onClose；onClose 幂等，
     本轮未改 AudioPanel UI 结构。N2（CSS 契约测试）、N3（滑杆 UI 映射）也未补。
