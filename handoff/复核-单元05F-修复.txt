D. S4 非规范金额串不再被判超限
- 实现：
  apps/web/src/game/steps.ts:50-62
    /** 只接受规范十进制整数分（无符号、无小数点、无指数、无前导零）；其他写法交给原有表单校验。 */
    const CANONICAL_CENTS = /^(0|[1-9]\d*)$/;
    export function withinLimit(value: string, limit: string | null): boolean {
      if (limit === null) return true;
      const text = value.trim();
      if (!CANONICAL_CENTS.test(text)) return true;
      const parsed = Number(text);
      const max = Number(limit);
      if (!Number.isSafeInteger(parsed) || !Number.isSafeInteger(max)) return true;
      return parsed <= max;
    }
- 测试：
  apps/web/tests/steps.test.ts:732-743
    expect(withinLimit("1e4", "5000")).toBe(true);
    expect(withinLimit("0x1389", "5000")).toBe(true);
    expect(withinLimit("+5001", "5000")).toBe(true);
    expect(withinLimit("5001.0", "5000")).toBe(true);
  同时保留空串、规范 0、恰好等于上限、规范超 1、超大规范数、limit=null 的断言。
- 结论：非规范写法返回 true（不判超限），点击提交后由 isPositiveCents/原表单校验
  给出“必须是整数分”的提示；合法的 5001/5000 仍判超限，不会误放行。
