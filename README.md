# RichMan（大富翁联机版）

一个从 C++ 控制台游戏改造成"开服电脑 + 浏览器多端联机"的回合制金融生存游戏。

## 当前状态（重要）

**这里目前只有文档，没有任何可运行代码。** 目录里的 .txt 是开发依据，不是成品。
第一位接手的 AI 从「单元 00」开始，不要以为工程已经存在。

- 方案版本：V1.3（施工版）
- 游戏版本：尚未开始（目标 V1.0）
- 代码：无
- Git：已初始化，只有文档提交

## 目录结构

    AGENTS.md              给 AI 的工作守则（AI 先读这个）
    README.md              你正在看的这份
    docs/
      INDEX.md             文件索引：每个文件是什么、什么时候读
      plans/               三份开发方案
      reference/           原始源码（只读）
      notes/               审计记录：V1.3 为什么这样改
    handoff/
      项目当前状态.txt     当前进度、下一单元、阻塞（每次交接都要更新）
      规则决策表.txt       规则编号与来源，单元 00 生成
    artifacts/test-logs/   测试日志（不入 Git）
    data/                  存档目录（不入 Git，绝不公网可访问）

工程代码（apps/、packages/、scripts/）由单元 00 创建，现在还没有。

## 怎么让 AI 开工

在项目根目录把这句话发给 AI（详情见 V1.3 第八节）：

> 请按 docs/plans/Richman分阶段联机开发方案_V1.3精简施工版.txt 的单元 00 开始。先读 AGENTS.md、方案、handoff/项目当前状态.txt，再检查实际目录与 Node/pnpm 版本，列改动文件与验收，然后实现。不要实现完整游戏，不要把尚未存在的测试标为通过，完成后写齐四类交接 TXT 并提交。

之后每次只填一个单元编号（01～09），一次只做一个单元。
