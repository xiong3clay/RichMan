二、规则编号与口径（实现与测试对应）
============================================================
R01 身份、轮次与金额（沿用源码 + 修复源码缺陷）
  - 2～10 人；初始 100 金币（10000 分）、信用 GOOD、无债务。
  - Cents = number 整数分，上限 10^12；协议字符串最多 13 位且绝对值 ≤ 10^12。
  - 利率整数基点 0～10000；利息四舍五入到分；乘除只走 mulDivRound/mulDivFloor。
  - 测试：shared/money-codec、game-core/money、protocol 边界。

R02 一轮流程与允许操作（修复源码缺陷 + 联机必须补充）
  - INTEREST → BANK_DUE → ACTION → BETTING →（第 3/6/9 轮）TAX → 轮末。
  - ACTION 只有当前座位可行动；成功经济操作消耗行动；失败不消耗、不重置倒计时。
  - 他人同意/拒绝请求不消耗其行动；银行到期只由借款人决定；BETTING 禁止经济操作；GAME_OVER 全拒。
  - 测试：engine-round（权限/行动消耗/推进）、full-game。

R03 银行借款、到期与多笔贷款（沿用源码 + 修复源码缺陷）
  - 普通贷款：信用 GOOD、金币>0、无未结清银行贷款；上限 = 金币一半向下取整。
  - 每轮 10%；N 轮生效、N+1 计息、N+3 轮计息后到期。
  - 到期当轮决策；余额不足或拒绝/超时 -> 该笔 DEFAULTED，其余贷款不受影响。
  - 测试：bank.test（bank_interest_50、default_no_repay、multiple_bank_loans）。

R04 信用与失信欠款（用户确认 D2）
  - 失信即永久 DEFAULTED：停息、不可还款、欠款冻结、不转 REPAID；不淘汰，仍可行动/私人借款/一倍下注。
  - defaultedBankDebtCents 为该玩家全部 DEFAULTED 贷款剩余之和，失信后不变。
  - 测试：bank.test（default_freezes_interest、default_no_repay）、engine tax/full-game。

R05 私人借款请求与生效时点（修复源码缺陷 + 用户确认 D5/D6）
  - 双方存活、不能自借、本金>0、利率 0～10000；同一借款人最多一个 PENDING（D6）。
  - 请求截止 = min(发起+请求时限, 当前窗口截止)；跨轮请求作废；同意才转账，且转账与建借条原子完成。
  - 请求必须携带借款人信用与失信欠款（D5）；出借人可取消/拒绝，借款人在等待时可取消（CANCEL_PRIVATE_LOAN）。
  - 测试：private-loans.test、engine-round（等待阻塞、取消）。

R06 私人计息、还款与催债（修复源码缺陷）
  - 下一轮才第一次计息，逐轮复利、漏轮补算；FROZEN/BAD_DEBT 不计息。
  - 还款/催收都要求 currentRound >= issuedRound、本轮利息已计入（INTEREST_NOT_ACCRUED）。
  - 催收上限 = min(剩余本息, max(0, 借款人金币))；超过上限拒绝并返回合法上限（AMOUNT_EXCEEDS_COLLECTIBLE）。
  - 借出当轮不能催；部分还款/催收只按实际金额减债。
  - 测试：private-loans.test（accrue、collect_partial、repay/collect 守卫）。

R07 赌博与锁定（联机必须补充）
  - 存活玩家同时锁注：bet 0～当前金币、guess 0/1、leverage 1/2（DEFAULTED 只能 1）；一次锁定。
  - 未开奖前对他人隐藏；提交不预扣；全员提交或超时补 0 后用 ctx.drawResult 开奖。
  - 猜对 +bet×leverage，猜错 -；亏损为负时生成 OVERDRAFT 贷款并归 0；一倍不得为负。
  - 测试：gamble.test（gamble_100、defaulted_leverage_only_1、privacy_hide_bets、timeout_fills_zero）。

R08 税收、危险自救与胜负（修复源码缺陷 + 用户确认 D4）
  - 第 3/6/9 轮按座位每人扣 20 金币；余额不足直接进失信/危险，不额外等无效窗口。
  - 危险自救窗口 60/45 秒：可紧急借款、催收、放弃；补到 >=0 立即结束；同人请求间隔 >=2 秒。
    引擎 TAX 分支额外容忍 REPAY_PRIVATE（界面无入口，不作为玩家可用操作）；文案按三操作。
  - 放弃/超时破产：合同转 BAD_DEBT/FROZEN、请求取消、银行贷款转 DEFAULTED。
  - 本轮所有应收税处理完再判胜负；仅剩 1 人获胜；全员破产无获胜者。
  - 测试：tax.test（tax_all_due_before_win、danger_partial_rescue、danger_give_up、danger_timeout）、full-game。

R09 破产后的债务与债权（修订版设计默认 + 用户确认 D3）
  - 破产不复活；本人未结清银行贷款全部 DEFAULTED；私人合同按借款人/出借人破产分别 BAD_DEBT/FROZEN。
  - FROZEN 后借款人再破产转 BAD_DEBT；坏账/冻结不计入可收回应收。
  - 测试：private-loans.test（borrower_bankrupt/lender_bankrupt）、tax.test。

R10 倒计时与节奏（用户确认 D4）
  - 标准 60/45/45/45/60 秒；快速 30/20/20/30/45 秒。
  - 阶段内所有必需操作完成立即前进；只有还有人没做完才由倒计时兜底；系统动作由服务器执行（advanceSystem），不依赖客户端命令。
  - 截止时先处理系统动作，迟到命令不能抢过超时。
  - 测试：engine-round（超时/推进）、tax/gamble（立即结算）。
