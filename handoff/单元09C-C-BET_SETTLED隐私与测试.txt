单元09C-C BET_SETTLED 传输层隐私拆分（唯一规格）
====================================================
日期：2026-11-08    基线：14f5cda（09C-B 已提交，66 文件 / 832 条全绿）
范围：只改 apps/server/src/ws.ts 的 visibleEvents 与 apps/server/tests/session.test.ts；

一、问题（现状，已核实）
1. engine.ts:584-588 的 BET_SETTLED 含全量 players：每人 betCents/guess/leverage/won/deltaCents/
   nextCents/overdraftCents，事件本身没有 audience，向房间内所有连接广播。
2. apps/server/src/ws.ts:145-154 只删除他人的 nextCents 与 overdraftCents，仍然下发他人的
   betCents、guess、leverage、won、deltaCents —— 改过的客户端能准确还原别人押了多少、猜的几、赢输多少。
3. apps/server/tests/session.test.ts:394-410（settlement_balance_private）把这个弱隐私写成了断言：
   players[1].betCents === "100"、typeof players[1].deltaCents === "string"。这是本轮唯一授权修改的旧断言。
4. 前端 apps/web/src/game/settlement.ts:130-134、apps/web/src/audio/audio.ts:323-324 只按 playerId 找本人条目，
   不依赖他人条目，因此本改动不需要改前端。

二、目标
每名玩家收到的 BET_SETTLED 只包含：
- 公共字段：seq/type/at、payload.round、payload.drawResult；
- players 数组：仅 viewer 自己的条目（字段完整），他人条目整体移除。
他人条目不得以任何形式出现（不保留 betCents/guess/leverage/won/deltaCents 等任何字段），
数组长度因此为 0 或 1。观看者未下注时 players 为 []。

三、实现（唯一改法）
apps/server/src/ws.ts 的 visibleEvents 中 BET_SETTLED 分支：
  const players = (payload.players as Array<Record<string, unknown>>)
    .filter(player => player.playerId === viewerId);
  return { ...event, payload: { ...payload, players } };
其余分支（TAX_CHARGED/DANGER_RESCUED、银行私有事件、eventsForPlayer）不变。
约束：
- 保留 event.seq/type/at 与 round/drawResult，客户端事件去重和结算卡依赖它们；
- 不要新增协议字段、不要把 filter 结果再删字段、不要改 wireCopy（cents→字符串仍由它完成）；
- 服务端内存与磁盘的 lastEvents 保留原始全量条目（用于复盘/审计），只裁剪“发给客户端”的副本；
  这一点写进注意事项，不要顺手改快照 schema 或 file-store。
