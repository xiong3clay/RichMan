1. 首次进入的玩家在 60 秒内知道“这局怎么走、钱怎么借、失信会怎样”，并能自己找到债务中心。

四、教程 5 页必须覆盖的事实（措辞可润色，规则不得改）
P1 一局怎么玩
   - 2～10 人同房，每人开局 100 金币；最后没破产的人获胜。
   - 每轮顺序：利息 → 银行到期 → 行动 → 全员下注 →（第 3/6/9…轮）税收 → 本轮结算。
   - 超时会替你推进：行动超时=结束行动；下注超时按 0 注；银行到期/自救超时按对应默认处理。
P2 银行借钱与失信
   - 普通贷款最多借“当前金币的 50%”，每轮利息 10%，借出后第 3 轮计息完到期（发放轮 N → N+3 轮）。
   - 到期余额够：可以还，也可以选择不还；余额不足：直接失信，没有选择窗口。
   - 拒绝或超时 = 永久失信：这笔银行贷款永久不能再还、也不再计息；不能再新增银行贷款；下注只能 1 倍；但不会被淘汰。
   - 私人负债不影响银行贷款资格。
P3 玩家之间借钱
   - 借款人自己填金额和利率（0～10000 基点，即 0%～100%），出借人 45 秒内（快速模式 20 秒）答复。
   - 同一个借款人同时最多 1 个待答复请求；同一出借人可以同时收到多人的请求。
   - 同意后立刻转账；每轮按约定利率计息；出借人可随时催收（上限=对方当前金币），借款人可随时还。
   - 借款人破产 → 这笔应收记坏账；出借人破产 → 合同冻结，不能再还/催收。
   - 失信者也能借，但出借人一定会看到“失信风险 + 失信欠款”。
P4 下注、纳税与自救
   - 每轮全员下注：猜 0 或 1、金额 0～当前金币、杠杆 1 或 2 倍。
   - 提交即锁定，不能改；全员提交后立即开奖，不必等倒计时；开奖前看不到别人的金额/猜测/杠杆。
   - 赢 = +注额×杠杆，输 = -注额×杠杆；2 倍输且余额不够时，差额自动转“赌博透支贷款”，按银行规则计息。
   - 失信玩家只能 1 倍；0 注 = 放弃本轮下注。
   - 每 3 轮每人交 20 金币税；余额不够进入“危险自救”（标准 60 秒），只能向玩家借款、催收、或放弃；放弃/超时 = 破产（私人债务转坏账、出借人应收冻结）。
P5 查账与隐私
   - 顶部固定轮次、阶段、倒计时；自身面板看金币、银行/透支/失信欠款、私人负债、可借额度、信用。
   - “债务中心”随时可开、不消耗行动：银行贷款逐条、私人合同按可还/可催收/冻结坏账分类。
   - 只能看到别人的昵称/座位/存活/信用/失信欠款，看不到别人的贷款与赌注明细。
   - 看教程、查债务都不消耗行动；教程状态不影响座位与恢复码。

五、规则页 8 节（标题固定，内容按实现写细节）
R1 目标与流程：人数、初始金币、每轮阶段顺序、超时默认、胜利条件。
R2 银行普通贷款：50% 上限、10%/轮、N+3 到期、余额不足直接失信、拒绝/超时永久失信、失信后不能新增银行贷款。
R3 赌博透支贷款：2 倍输的差额、按银行规则计息、失信欠款不可偿还、与普通贷款分开展示。
R4 私人借贷：利率 0～10000 基点、45 秒答复、单借款人 1 个待答复、同意即转账、每轮计息、催收上限、坏账/冻结。
R5 下注：0～当前金币、猜 0/1、1/2 倍、提交锁定、全员提交立即开奖、超时 0 注、失信 1 倍、开奖前隐私。
R6 税收与危险自救：每 3 轮 20 金币、余额不足进自救、自救可用手段（私人借款/催收/放弃）、破产结算与超时。
R7 信用与失信：永久失信、不淘汰、只能 1 倍、仍可借私人钱但显示风险、失信欠款金额。
R8 隐私与查询：自己可见字段、他人可见字段、债务中心入口与“不消耗行动”。

六、交互规格
- 首次自动打开：App 首次挂载时 tutorialSeen=false → tutorialOpen=true；已读 → 不打开。
- 关闭路径：跳过教程、末页“我知道了”、关闭按钮，三者都写 seen 后关闭；写失败也关闭（不阻断）。
- 重看：入口页/大厅/对局内的“新手教程”“规则说明”随时可开；教程从第 1 页开始。
- 打开教程/规则期间，底层页面的倒计时照常由服务端推进，但 UI 不得因此发命令；关闭后按最新快照重建。
- 键盘：Esc 关闭（可选实现，不强制测试）；遮罩点击不关闭。
- 焦点：打开时焦点进入面板（focus 首个按钮），关闭后尽量回到触发按钮；dom-harness 不支持则只做不报错的 best-effort。
